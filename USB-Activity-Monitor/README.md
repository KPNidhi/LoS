# USB Activity & Data Leak Risk Monitor
In today’s digital environment, USB storage devices are widely used to transfer files between computers, but they can also create security risks such as unauthorized data copying, accidental data leakage, and the transfer of suspicious files. Many systems lack a simple, lightweight mechanism to monitor USB-related file activities and identify potentially risky data transfers.
The USB Activity & Data Leak Risk Monitor aims to develop a Linux-based security application using shell scripting to monitor USB-related activities, detect suspicious file operations, identify files that may contain sensitive information, and generate activity logs and risk alerts. The application helps users understand potential data leakage incidents and improve endpoint security through automated monitoring and reporting.

## Technologies Used
- Ubuntu Linux
- Bash scripting
- grep
- awk
- sed
